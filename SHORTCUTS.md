# Keyboard Shortcuts & Controls

## General

| Shortcut | Action |
|---|---|
| `Esc` | Exit fullscreen / restore UI |
| `F11` | Toggle fullscreen |
| `Ctrl+Esc` | Force exit fullscreen |
| `Alt+F4` | Close application |
| `Ctrl+O` | Open folder |
| `Ctrl+G` | Go to image / PDF page |

## Enhancements

| Shortcut | Action |
|---|---|
| `Ctrl+R` | Reset all enhancements |

## Drawing

| Shortcut | Action |
|---|---|
| `Ctrl+Z` | Undo last line |
| `Ctrl+Shift+A` | Toggle antialiasing |
| `Ctrl+Shift+P` | Test pen pressure |

## Zoom

| Shortcut | Action |
|---|---|
| `Ctrl++` | Zoom in |
| `Ctrl+-` | Zoom out |
| `Ctrl+0` | Reset zoom |
| Mouse wheel | Zoom in / out |

## Transform (via context menu)

| Shortcut | Action |
|---|---|
| `Ctrl+H` | Flip horizontal |
| `Ctrl+V` | Flip vertical |

## Navigation

| Input | Action |
|---|---|
| Middle-click | Next image |
| Right-click drag | Pan (when zoomed in) |

## Video Playback

| Shortcut | Action |
|---|---|
| `Space` | Play / Pause |
| `M` | Toggle mute |
| `Left Arrow` | Seek back 5 seconds |
| `Right Arrow` | Seek forward 5 seconds |

## Drag & Drop

| Drop Target | Action |
|---|---|
| Folder | Open folder and load all media |
| PDF file | Open PDF viewer |
| EPUB file | Open EPUB viewer |
| Image / GIF / Video file | Open file and load parent folder for navigation |

## Supported Formats

- **Images:** `.jpg`, `.jpeg`, `.png`, `.bmp`, `.gif`
- **Videos:** `.mp4`, `.avi`, `.mkv`, `.mov`, `.webm`, `.flv`, `.wmv`
- **Documents:** `.pdf`, `.epub`
